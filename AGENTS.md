# Mangekyo

- Deploy this project with GitHub Pages using `.github/workflows/pages.yml`; do not publish through Sites.
- Preserve relative asset URLs and service-worker cache isolation by deployment path.
- Keep interface copy in `src/i18n`; translate display labels without changing stored exercise or eye identifiers.
- Do not automatically open sidebar previews. Provide clickable links unless the user asks for a preview.
- Run `npm test` and `npm run build` for changes affecting application or deployment behavior.
